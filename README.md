# Bryggeboka

Bryggeapp for kaffe basert på Tim Wendelboes bryggeguider og videoer.
Installerbar nettapp (PWA) som virker uten nett.

**Bruk:** https://gromito.github.io/bryggeboka/

- Guidede timere: pour over, filtermaskin, French press, AeroPress (vanlig og sterk), iskaffe, espresso og cupping
- Kalkulator for kaffe og vann per metode
- Leksjoner, smaksveileder, ferskhetsmåler og cuppingskjema
- Bryggedagbok (lagres lokalt i nettleseren)

Uoffisielt hjelpemiddel. Originalguidene finnes på [timwendelboe.no](https://timwendelboe.no/pages/learn).
